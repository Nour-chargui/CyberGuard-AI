# 🛡️ CyberGuard AI - Assistant SOC Intelligent

Plateforme d'aide à la décision pour analystes SOC utilisant le **RAG** et des **Agents IA**.

## 🚀 Fonctionnalités
- **RAG (Retrieval-Augmented Generation)** : Recherche sémantique dans la documentation interne.
- **Agent Autonome** : Analyse automatique de criticité (score CVSS).
- **Privacy-by-Design** : Anonymisation des adresses IP et emails via Regex.
- **Performance** : Inférence ultra-rapide via Groq LPU.

## 🛠️ Stack Technique
- **Frontend** : React.js, Tailwind CSS
- **Backend** : FastAPI, Python 3.12
- **IA** : LangChain, Groq (Llama 3.3), HuggingFace (Embeddings locaux)
- **Base de données** : ChromaDB

## 📦 Installation
1. Cloner le projet
2. Backend : `pip install -r requirements.txt`
3. Frontend : `npm install`
